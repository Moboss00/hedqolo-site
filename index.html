Elonako — la gestion scolaire, repensée de bout en bout.

Une plateforme complète pour établissements scolaires et universitaires : bulletins numériques, présences, facturation automatisée, communication parents-école — accessible sur le web comme sur mobile.

  • Backend Django + frontend Next.js + application mobile native Flutter (iOS/Android)
  • Plus de 20 modules connectés : notes, présences, emploi du temps, paiements, incidents, alertes de décrochage…
  • QR code de sortie d'école sécurisée et bulletins vérifiables
  • Facturation récurrente automatique, intégration Mobile Money en cours (MTN, Airtel)
  • Gestion multi-établissements, du K-12 à l'université, avec mode hors-ligne
